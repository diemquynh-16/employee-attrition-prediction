# Data

Đặt file **IBM Employee Attrition Dataset** tại thư mục này và đổi tên thành:

```text
IBM.csv
```

Bộ dữ liệu có 13 cột:

- `Age`
- `Attrition`
- `Department`
- `DistanceFromHome`
- `Education`
- `EducationField`
- `EnvironmentSatisfaction`
- `JobSatisfaction`
- `MaritalStatus`
- `MonthlyIncome`
- `NumCompaniesWorked`
- `WorkLifeBalance`
- `YearsAtCompany`

Biến mục tiêu của bài toán là `Atrrition`, gồm hai lớp:

- `Yes`
- `No`
